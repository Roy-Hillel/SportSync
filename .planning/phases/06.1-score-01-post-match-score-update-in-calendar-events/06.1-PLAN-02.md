## Objective

Update the iCal generator to:

1. **Score in title**: When a match is `closed` (full-time) and scores are available, replace the event summary from `"HomeTeam vs AwayTeam"` to `"HomeTeam 3–1 AwayTeam"`. Pre-match and live events keep the original `vs` format.
2. **SEQUENCE field**: Add a `sequence` property to every `createEvent()` call, using `Math.floor(event.lastFetchedAt.getTime() / 1000)`. This is a monotonically increasing integer — when a score update arrives, `lastFetchedAt` advances and so does `SEQUENCE`, signalling to calendar clients (Google, Apple, Outlook) that the event has been updated.

This is the only user-visible change in Phase 06.1 — calendar events will show final scores after matches end.

```typescript
/**
 * Build the iCal event summary (title).
 *
 * Post-match (status === 'closed' with scores available):
 *   "Real Madrid 3–1 Barcelona"
 *
 * All other states (pre-match, live, postponed, etc.):
 *   "Real Madrid vs Barcelona"
 *
 * The en-dash (–) is used as the score separator per locked decision.
 */
function buildSummary(event: SportEventRow): string {
  if (
    event.status === "closed" &&
    event.homeScore != null &&
    event.awayScore != null
  ) {
    return `${event.homeTeamName} ${event.homeScore}–${event.awayScore} ${event.awayTeamName}`;
  }
  return `${event.homeTeamName} vs ${event.awayTeamName}`;
}
```

Key details:
- Uses `–` (en-dash U+2013), not `-` (hyphen), per the locked format decision.
- `event.homeScore != null` covers both `null` and `undefined` (handles the case where old DB rows lack scores).
- Only triggers when `status === "closed"` — live matches keep the `vs` format even if partial scores appear.
